# ENTime - Bill of Materials (BOM)

Список компонентов для сборки устройства точной синхронизации времени ENTime.

---

## Основные компоненты

| # | Компонент | Описание | Кол-во | Примечание |
|---|-----------|----------|--------|------------|
| 1 | **ESP32-S3-DevKitC-1** | Микроконтроллер | 1 |  |
| 2 | **ILI9341 TFT** | Дисплей 3.2" 240×320 SPI | 1 | С тачем XPT2046 |
| 3 | **NEO-M8N** | GPS модуль с PPS | 1 | Обязательно с PPS выходом |
| 4 | **DS3231** | RTC модуль I2C | 1 | |
| 5 | **INA226** | Монитор напряжения/тока/мощности I2C | 1 | Для уровня заряда в статус-баре |
